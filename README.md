# Donkey Kong Game

## 🚀 How to Build and Run

### Using VS Code

* **Compile and Run:** Press `Ctrl + F5`
* **Debug:** Press `F5`

### Using the Terminal

* **Compile only:**
    ```bash
    make
    ```
* **Run the executable:**
    ```bash
    make run
    ```
